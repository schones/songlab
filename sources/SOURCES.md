# Sheet-music sources

Public-domain scans used as sources for the Voicing Explorer's public
pieces (see `docs/STATUS.md`, "Public pieces track"). The PDFs live in
this folder but are gitignored (`sources/*.pdf`); only this file is
committed. Re-download by IMSLP file index: the link form is
`https://imslp.org/wiki/Special:ImagefromIndex/<index>` (IMSLP shows a
disclaimer first). Every file below was published in the United States
in 1930 or earlier, so it is US public domain; the composers'
life + 70 status elsewhere varies (IMSLP tags most as non-PD Canada).

Downloaded 2026-10-20 from IMSLP. Only the original 1930-or-earlier
publications are kept — no later reprints, no Gershwin Song-Book piano
solos, no Hal Leonard songbook reprints, no New Real Book lead sheets.

## I Got Rhythm
- Composer: George Gershwin; lyrics Ira Gershwin
- Year / publisher / plate: 1930, New York: Warner Bros. Music Corp. (no plate given; voice and piano first edition, scanned from the University Society "Music by Gershwin" reprint of first editions, No.12 pp.57–60, 1975)
- IMSLP page: https://imslp.org/wiki/I_Got_Rhythm_(Gershwin,_George)
- IMSLP file index: 1012534
- Local file: `i-got-rhythm-1930-warner.pdf` (4 pages, 3.7 MB; served by petruccilibrary.us)
- US public domain (published 1930 or earlier)
- This scan is a later reprint (© 1930 WB Music Corp., Renewed; from The University Society "Music by Gershwin", with a c.1980 header note) and carries editorial chord symbols that may postdate 1930. SongLab uses the notes only (melody and piano-part pitches); chord symbols are derived by analysis, and the header text is not used.
